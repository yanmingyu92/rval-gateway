# Reference Test Report — Phase 3 (sanitized)

**Date:** 2026-09-02 · **Scope:** structure-level benchmark of the gateway
report against two vendor sample validation reports, anonymized as
**Vendor A** (package: abind) and **Vendor B** (package: xfun).

**Confidentiality:** the vendor sample PDFs are vendor-confidential, remain on
file outside this repository, and were never copied into it. This report
contains structure-level comparison only — no vendor-confidential numbers or
verbatim vendor text. Raw alignment data lives in `internal_reference/`
(gitignored, internal-only). Section lists were extracted earlier with the
E2 experiment's stdlib PDF text extractor and curated into anonymized
reference JSONs; this benchmark reuses those curated lists.

## Method

The gateway's one-page report (`gateway/templates/report.html`) was aligned
section-by-section against both vendor reports' section lists. Coverage
states: **aligned** / **partial** / **deliberate-gap** / **extended** (ours,
no vendor counterpart).

## Where we align

| Gateway report block | Vendor A | Vendor B | State |
|---|---|---|---|
| Identity header (package, version, origin, timestamp) | Package Information | Header / Package Details | aligned |
| Per-metric breakdown ({riskmetric} 0–1 per metric) | Risk Scoring (subscores) | Metric Overview + per-family score sections | aligned |
| CRAN metadata (title, maintainer, license, dates) | Repository Information | Package Details | aligned |
| Community/repository signals (downloads, repo activity) | Risk Scoring (usage inputs) | Package Freshness family | partial (we show raw values + evidence IDs) |
| Provenance footer (tool/R/riskmetric/config versions) | Assessment Execution Log (annex) | System Information | aligned |
| Classification & sign-off slots | Classification + Approvals | — | partial (ours render PENDING HUMAN REVIEW) |

## What we deliberately lack (Tier-2 scope, not Tier-1 screening)

- **Signed function-level test evidence** (coverage annex): requires executing
  the assessed package's tests — disabled by policy in v1 (assessed code is
  never executed; code-executing riskmetric metrics are excluded). A Phase 4+
  sandboxed-container item.
- **Validated-environment statement** (OS/R/BLAS/locale annex) and
  **dependency version pinning evidence**: Tier-2 qualification artefacts;
  the environment-pinning evidence mechanism (snapshot URLs / lockfiles /
  image digests) is identified but not generated by the gateway.
- **Approval timeline / signature blocks**: our workflow history lives in the
  append-only hash-chained audit trail, not the report body.
- **Reverse-dependency section**: no deterministic source wired in v1 (the E2
  prototype suppressed the equivalent section by the same no-evidence rule).

## What we add (no vendor counterpart)

- **Decision layer**: config-driven GO / GO-WITH-CONDITIONS / NO-GO banner
  keyed to intended-use tier, with **every rule evaluated shown with its
  inputs and thresholds** — the vendors provide qualification evidence; the
  gateway makes intake decisions.
- **Conditions list** attached to non-GO outcomes (actionable, config-driven).
- **Evidence register**: every fact carries an evidence ID with source and
  collection timestamp; sections lacking evidence are suppressed rather than
  drafted. Neither vendor report links per-fact sources at this granularity.
- **Pinned-artifact anchor**: tarball sha256 + pinned version recorded per
  assessment (vendor samples assess a snapshot but do not surface a content
  hash in the report header).

## Position statement

The tools serve different tiers of one strategy: **the gateway makes Tier-1
intake screening decisions; the vendors provide Tier-2 qualification
evidence.** A gateway NO-GO (or any gxp-critical intended use) is precisely
the trigger for purchasing/vendor-style full qualification. The structural
benchmark confirms the gateway covers the factual core needed for that
screening decision (identity, repository, risk metrics, provenance) while
deliberately omitting execution-based evidence that belongs to Tier 2.
